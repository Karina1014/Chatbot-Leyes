# 📘 Chatbot de Leyes con FastAPI + Qdrant + Gemini

Este es un proyecto en Python que implementa un chatbot legal usando **FastAPI**, **Qdrant** como base vectorial, y **Gemini (Google Generative AI)** como modelo generativo. Permite subir documentos `.docx`, consultarlos mediante preguntas, y guardar las respuestas en un archivo Excel.

---

## 🚀 Tecnologías utilizadas

- Python 3.8+
- FastAPI
- Qdrant
- Google Generative AI (Gemini)
- Sentence Transformers
- Openpyxl / python-docx
